# edubridge · конструктор материалов

Конструктор постов, Stories, обложек Reels, Telegram и YouTube для
edubridge — строго по брендбуку. Работает целиком в браузере: сервера нет,
фото и видео никуда не отправляются. Один файл `index.html`, внутри уже
лежат шрифты Onest и Unbounded, логотипы, иконки и флаги.

Сделан на основе [card-maker-wemedia](https://github.com/ehroz1/card-maker-wemedia):
оттуда перенесены видео на карточках (обрезка, экспорт в MP4/WEBM со звуком),
установка на телефон и работа офлайн, экспорт в ZIP. Новое — **экран выбора
шаблона** с живым превью и редактор, где у каждого слайда своя понятная форма.

---

## Как пользоваться

### 1. Выбор шаблона

Первый экран — галерея всех шаблонов. Превью рисуются тем же движком, что и
экспорт, с примерами текста из брендбука, — видно ровно то, что получится.

- Фильтры сверху: **Посты**, **Stories**, **Reels и хайлайты**, **Telegram**,
  **YouTube**.
- У многослайдовых шаблонов на превью — стопка карточек и число слайдов.
- Нажми на шаблон — откроется окно: большое превью, лента всех слайдов
  (листается стрелками ← →), главное правило, структура и объём из раздела
  Tone of Voice, какие слайды можно добавить.
- **Начать с примером** — слайды с текстами-образцами, их удобно просто
  переписать. **Пустой шаблон** — та же раскладка без текстов.
- Блок **Продолжить работу** — черновики, сохранённые в этом браузере.

### 2. Редактор

Экран поделён на три части: слева слайды, в центре превью, справа поля
текущего слайда.

- Правки в полях сразу видны на превью.
- **+ Слайд** добавляет слайд из разрешённых для шаблона типов (у гайда —
  шаг, ошибки, чек-лист, финал; у истории — вопрос-ответ, цитата…).
  На миниатюре слайда — кнопки «раньше/позже», «дублировать», «удалить»;
  слайды можно и перетаскивать.
- Счётчики «4/9», прогресс карусели и номера шагов гайда ставятся сами.
- В длинном тексте строка, начинающаяся с «- », становится пунктом списка
  с дугой-маркером вместо буллета.
- Списки в форме (факты, сроки, ответы квиза, пункты чек-листа) — строки
  добавляются, переставляются и удаляются кнопками рядом.

### 3. Фото и видео

- Перетащи файл прямо на рамку на превью, нажми на пустую рамку или на
  «Загрузить» в поле формы. **⌘V** вставляет картинку из буфера обмена.
- Кадр двигается перетаскиванием, масштаб — колесом мыши, щипком или
  ползунком «Масштаб». «Сбросить кадр» возвращает как было.
- Видео можно поставить туда, где это имеет смысл: обложки, Reels, титры,
  фото на новостях и партнёрских постах. После загрузки откроется окно
  обрезки. Экспорт — MP4 (или WEBM, если браузер не умеет MP4), со звуком.
- Если фото меньше, чем нужно рамке, появится предупреждение «будет мыльно».
- Фото и видео **не сохраняются** между сессиями — только тексты и настройки.

### 4. Строго по брендбуку

Шрифты, цвета, отступы и сетка зашиты в шаблоны и не меняются. Можно:

- выбрать разрешённый вариант — фон универсального слайда (Paper, белый,
  Sky Tint, Bridge Blue, Ink), рубрику обложки Telegram или Reels, плашки
  «Дедлайн» / «Гранты»;
- в блоке **Подстройка текста** уменьшить или увеличить кегль и
  интерлиньяж, если текст не влезает.

Под превью — проверка: «Заголовок: 4 строки, по брендбуку до 3», «Текст не
помещается», «мало пикселей». Кнопка **Уместить** сама уменьшает кегль,
пока текст не поместится (не меньше 70%). Красная точка у миниатюры —
на этом слайде есть предупреждения.

Кнопка с сеткой в верхней панели показывает модульную сетку и безопасные
зоны: 6 колонок и поля 80 px у поста, обрезку 3:4 в профиле (пунктир Coral),
зоны интерфейса Stories (250 px сверху, 340 px снизу), зону обложки Reels
в сетке (центральные 1080×1440).

### 5. Экспорт

Кнопка **Экспорт** справа сверху:

- формат PNG или JPG, размер 1× или 2×;
- все слайды одним ZIP, все по одному или только текущий;
- **⌘S** — экспорт всех слайдов.

Слайды с видео выгружаются в MP4/WEBM. Титры для Reels и плашка спикера без
фона — PNG с прозрачностью, чтобы наложить в монтаже.

### Горячие клавиши

⌘Z — отменить, ⌘⇧Z (или ⌘Y) — повторить, ⌘S — экспорт, PageUp/PageDown —
соседний слайд, Esc — закрыть окно. Внутри текстовых полей ⌘Z работает как
обычно, по буквам.

### Установка на телефон и офлайн

На телефоне появится баннер «Установить» (на iPhone — подсказка про
«Поделиться → На экран «Домой»»). После установки конструктор открывается
отдельной иконкой и работает без интернета. Нужен хостинг по http(s) —
GitHub Pages или `python3 -m http.server`; при открытии файлом с диска
офлайн-режим браузеры не разрешают, но само приложение работает.

## Как выложить для коллег (GitHub Pages)

1. В репозитории открой **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты появится ссылка вида
   `https://ТВОЙ_ЛОГИН.github.io/edubridge/` — её и отправляй.

`index.html`, `manifest.webmanifest` и `service-worker.js` всегда
собираются и выкладываются вместе — офлайн-режим работает, только если все
три лежат рядом.

## Для разработчика

### Сборка

Приложение, которое реально открывается, — сгенерированный `index.html`.
Править нужно `src/` и `brand/`, потом пересобрать:

```bash
pip3 install fonttools brotli   # урезает шрифты до латиницы и кириллицы с казахскими буквами
python3 build.py
python3 -m http.server 8000     # http://localhost:8000
```

Без fontTools сборка тоже пройдёт, просто шрифты встроятся целиком и файл
станет тяжелее.

### Структура

```
index.html               готовое приложение (генерируется)
manifest.webmanifest     манифест PWA (генерируется)
service-worker.js        офлайн-кеш (копируется из src/)
build.py                 сборка
src/
  render.js              движок Canvas: цвета, шрифты, перенос, плашки, логотип, дуга, фото
  templates.js           ВСЕ шаблоны: типы слайдов (KINDS) и наборы (TEMPLATES)
  app.js                 интерфейс: выбор шаблона, редактор, фото/видео, отмена, экспорт
  styles.css             оформление интерфейса (светлая и тёмная тема)
  index.template.html    каркас страницы
brand/
  fonts/                 Onest 400–800 и Unbounded 500–700 (SIL OFL, лицензии рядом)
  logo/                  логотип и дуга — из них берутся только контуры
  glyphs/                иконки для макетов — Phosphor Fill (MIT)
  ui/                    иконки интерфейса — Phosphor Bold (MIT)
  flags/                 круглые флаги Circle Flags (MIT)
  pwa-icon*.svg/png      иконка приложения
brandbook/               брендбук (HTML из Claude Design) — источник всех цифр
```

### Как добавить шаблон

1. В `src/templates.js` опиши тип слайда в `KINDS`: `format`, `fields`
   (поля формы с примерами `sample`), `tune` (что можно подстраивать) и
   `draw(ctx, data, env)`. Внутри `draw` — только примитивы из `render.js`
   и `env.photo()` для рамок фото.
2. Добавь запись в `TEMPLATES`: группа, рубрика, описание, правила из
   Tone of Voice, стартовые слайды и разрешённые типы.
3. `python3 build.py` — шаблон появится на экране выбора сам.

### Известные ограничения

- В Unbounded нет казахских букв Ә Ғ Қ Ң Ө Ұ Ү Һ — в заголовках они
  автоматически набираются Onest того же веса.
- Фото и видео живут только в памяти вкладки; тексты и настройки черновиков
  — в `localStorage` браузера.
- MP4 умеют писать Chrome, Edge и Safari; Firefox выгружает видео в WEBM.
